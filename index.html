Engineering Anatomy

How 100/100 Lighthouse Was Achieved

Deep dive into the 5 core optimization vectors implemented in the Aura Engine.

01

Critical CSS Inlining

Above-the-fold layout primitives and hero skeleton styles are directly embedded in a <style> block (< 8KB), enabling the browser to render the initial viewport without blocking on external stylesheet roundtrips.

02

Asynchronous CSS Delivery

Non-critical CSS is loaded asynchronously via rel="preload" as="style" onload="this.rel='stylesheet'" with a progressive <noscript> fallback.

03

LCP Image Priority & Preload

The primary LCP hero image is declared via <link rel="preload" as="image" fetchpriority="high"> in document head, allowing the network parser to fetch it concurrently with initial HTML parsing.

04

Strict Aspect-Ratio & Zero CLS

Every image specifies explicit width and height attributes and CSS aspect-ratio containers, pre-allocating layout boxes and preventing Cumulative Layout Shifts.

05

Script Deferral & RAF Throttling

All JavaScript is deferred (defer) and executed after initial paint. Scroll and resize listeners are throttled using requestAnimationFrame to eliminate main-thread jank.

06

Resource Hints & Preconnect

Early DNS resolution and TLS handshakes are established with critical third-party CDNs using <link rel="preconnect"> and crossorigin attributes.
